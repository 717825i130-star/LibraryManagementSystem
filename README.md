# Library Management System

## About the Project
The Library Management System is a Java-based mini project developed using Object-Oriented Programming (OOP) concepts. It is designed to simplify basic library operations and provide a simple way to manage library resources.

## Objectives
- To develop a library management application using Java.
- To understand and implement Object-Oriented Programming concepts.
- To organize library-related information efficiently.
- To improve practical Java programming skills.

## Technologies Used
- **Programming Language:** Java
- **IDE:** Eclipse
- **Version Control:** Git
- **Repository Hosting:** GitHub

## Features
- Manage book information.
- View available library books.
- Perform basic library operations supported by the program.
- Organize the application using Java classes and methods.


## Project Structure
```text
LibraryManagementSystem/
├── src/          # Java source files
├── bin/          # Compiled class files
├── .classpath    # Eclipse classpath configuration
└── .project      # Eclipse project configuration
```

## How to Run
1. Clone or download this repository.
2. Open Eclipse IDE.
3. Select **File → Import → Existing Projects into Workspace**.
4. Select the downloaded project folder.
5. Open the `src` folder and locate the main Java class.
6. Right-click the main class and select **Run As → Java Application**.
